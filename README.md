As Immich updated to version 3.0.0, old devices that use x86-64-v1 architecture stopped working with the immich-machine-learning. In this repository I'll post the custom image that I've made using immich 3.0.3 for fix that problem and the step by step of how to make it in any immich version.

What you will need:
A server running immich with docker
A newer linux or WSL environment
